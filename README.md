📄 PDF Editor

Editor de PDF leve, moderno e responsivo, desenvolvido com HTML, CSS e JavaScript.

✨ Recursos

- Visualizar PDFs
- Ampliar e girar páginas
- Excluir páginas
- Exportar documentos editados
- Interface adaptada para celular e computador

🛠️ Tecnologias: HTML5 · CSS3 · JavaScript · PWA

🌐 Acesso: GitHub Pages

📱 Instalação: Acesse pelo Chrome e adicione à tela inicial.
